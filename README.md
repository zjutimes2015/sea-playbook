## Nightly manuscript review gate

Before a unit counts as publishable, run the stack in [REVIEW-STACK.md](./REVIEW-STACK.md):

1. **proselint** on new/changed `.md` (style / redundancy)
2. **LanguageTool** for EN grammar/spelling
3. **calibre** convert + TOC/fonts check before any KDP upload
